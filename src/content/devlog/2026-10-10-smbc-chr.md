The disassembly covers PRG code and data only — the 8KB of CHR pattern tables is the one asset it omits. Extracted the CHR section from a donor iNES image (32KB PRG + 8KB CHR, NROM) whose PRG boot bytes match `smb.asm: Start`, and embedded it as a C array at `src/data/chr.c`: two pattern tables of 256 16-byte tiles, ready for a frontend renderer.

## Provenance

The file header records the extraction command (`dd`, offset 32784, 8192 bytes), the donor ROM's SHA-256, and the CHR's own SHA-256 and CRC-32 — so the table is reproducible and verifiable against any matching dump. A test checksums the array against the donor CHR's CRC-32; `make test` is green.
